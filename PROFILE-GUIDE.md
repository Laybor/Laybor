# Mantener el perfil de Laybor

Borrador local sobre una copia de https://github.com/Laybor/Laybor. El README mantiene el inglés del original para facilitar su lectura internacional.

El workflow actualiza únicamente el bloque ACTIVITY con los últimos repositorios públicos propios. Excluye forks, archivados y el perfil. Se ejecutará diariamente, al hacer push a main o manualmente desde Actions cuando se publique. Usa github.token; no requiere un token personal. La ejecución en GitHub aún debe comprobarse. Las protecciones de rama pueden impedir el push y GitHub puede suspender ejecuciones programadas en repositorios públicos inactivos.

Al avanzar: añadir el enlace público del organizador, una captura real cuando funcione y un enlace a su release cuando exista. Actualizar estados solo después de verificar los hitos. El script no deduce funciones terminadas a partir de commits.

Ejecutar scripts/update-profile.ps1 desde PowerShell para actualizar localmente.

Bio propuesta: Building useful tools from everyday problems. Web experiments, desktop apps, and a few side quests. 🦇

# Mantener el perfil de Laybor

Borrador local sobre una copia de https://github.com/Laybor/Laybor. El README mantiene el inglés del original para facilitar su lectura internacional.

El workflow actualiza el bloque ACTIVITY, las tarjetas assets/stats.svg y assets/languages.svg, y la animación assets/contribution-snake.svg. La actividad excluye forks, archivados y el perfil. Las estadísticas cuentan proyectos públicos originales, incluidos archivados, sin contar el perfil. Los lenguajes se ponderan por bytes de código; no indican dominio de una tecnología. Se ejecuta diariamente, al hacer push a main o manualmente desde Actions. Usa github.token; no requiere un token personal. Las protecciones de rama pueden impedir el push y GitHub puede suspender ejecuciones programadas en repositorios públicos inactivos.

Logos: Skill Icons. Badges: Shields.io. Serpiente: Platane/snk. Los créditos están en el README. La portada y el diagrama usan animación CSS en SVG, con soporte para movimiento reducido. El diagrama del organizador es conceptual. Los logos Qt representan el framework que se explorará mediante PySide6.

Al avanzar: añadir el enlace público del organizador, una captura real cuando funcione y un enlace a su release cuando exista. Actualizar estados solo después de verificar los hitos. El script no deduce funciones terminadas a partir de commits.

Ejecutar scripts/update-profile.ps1 desde PowerShell para actualizar localmente.

Bio propuesta: Building useful tools from everyday problems. Web experiments, desktop apps, and a few side quests. 🦇
